# GlassBox Earned Value Management

Benchmarking for stochastic Earned Value Management, comparing the performance of the Explainable Boosting Machine (EBM) model against other machine learning models.

## Benchmarked Models

This project evaluates the following regression models:

- [Explainable Boosting Machine (EBM)](https://interpret.ml/docs/python/api/ExplainableBoostingRegressor.html): GAM ensemble boosting model.
- [Random Forest](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestRegressor.html): ensemble bagging model.
- [Extreme Gradient Boosting (XGBoost)](https://xgboost.readthedocs.io/en/stable/python/python_api.html): ensemble boosting model.
- [Support Vector Regression (SVR)](https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVR.html#sklearn.svm.SVR): kernel-based model.
- [Elastic Net](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.ElasticNet.html#sklearn.linear_model.ElasticNet): regularized linear model.
- [Deep Learning with fastai](https://docs.fast.ai/): neural network model.
